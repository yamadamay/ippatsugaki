# 手動受け入れテスト手順書

自動テストでカバーできない項目を、実機で確認するための手順書です。
確認できた項目は「OK」、確認できていない項目は「未確認」と記録してください。

## 準備

1. アプリをビルドする（README参照）。
2. 実行前に `draft.txt`（READMEの「一時保存と復旧」参照）が存在しないことを確認する。存在する場合は削除する。
3. アプリを起動する。

## 1. 確定から保存、初期状態への復帰（一連の流れ）

1. お題と必須要素が表示されていることを確認する。
2. 「引き直し」を数回押し、お題と必須要素の両方が変わることを確認する。直前と同じ主体・出来事・必須要素が連続しないことを確認する。
3. 制限時間を「10分」以外にし、「確定」を押す。確認ダイアログの初期選択が「戻る」であることを確認し、「確定して開始」を押す。
4. タイマーが動き出し、エディタに入力できることを確認する。
5. 文章を入力し、文字数が約200ミリ秒後に更新されることを確認する。改行・半角スペース・全角スペース・タブが数えられないことを確認する。
6. 数分待ち、「ギブアップ」→「はい」で保存画面になることを確認する。
7. タイトルを入力し、保存ダイアログで任意の場所に保存する。拡張子 `.txt` が付くことを確認する。
8. 初期状態に戻り、お題が変わり、エディタが空になっていることを確認する。
9. 保存したファイルがUTF-8（BOMなし）・改行LFのプレーンテキストで、本文のみ（タイトルを含まない）であることを確認する。

## 2. 時間切れの瞬間にIME変換中だった場合

1. 制限時間を10分で確定するか、残り時間が少ない状態にする。
2. 日本語入力で変換中（未確定）の状態のまま時間切れにする。
3. 時間切れの瞬間にエディタが読み取り専用になり、変換中の文字が確定も破棄もされず残ることを確認する。
4. 保存フローで保存し、未確定だった文字が保存されていないこと（確定済みの本文のみ保存されること）を確認する。

## 3. 保存のキャンセルを繰り返したときの2段階確認

1. 文章を書いて保存画面に進む。
2. タイトル入力またはファイル選択でキャンセルする。
3. 確認A（初期選択「いいえ」）が出ることを確認する。「いいえ」でタイトル入力に戻ることを確認する。
4. 再度キャンセルし、確認Aで「はい」→確認B（初期選択「いいえ」）で「いいえ」を選び、タイトル入力に戻ることを確認する。
5. 再度キャンセルし、確認A「はい」→確認B「はい」で、初期状態に戻り、`draft.txt` が削除されていることを確認する。

## 4. 強制終了からの復旧

1. 文章を書く（30秒以上待つ、または一時停止して一時保存が完了していることを確認する）。
2. アプリを強制終了する。
3. 再起動し、「前回の文章が残っています。復旧しますか？」（初期選択「はい」）が出ることを確認する。
4. 「はい」で本文が読み込まれ、保存画面（ギブアップ扱い）に進むことを確認する。続きを書けないことを確認する。
5. 保存して、本文が失われていないことを確認する。
6. 復旧で「いいえ」→「二度と復活できません。削除しますか？」（初期選択「いいえ」）→「いいえ」で手順3の確認に戻ることを、再度「いいえ」→「はい」で `draft.txt` が削除され初期状態に進むことを確認する。

## 5. スリープ復帰時の自動一時停止

1. 執筆中にPCをスリープさせる。
2. 復帰させ、「PCの停止を検出したため一時停止しました」が表示され、一時停止中になっていることを確認する。
3. スリープしていた時間がタイマーに加算されていないことを確認する。
4. 「再開」で執筆を続けられることを確認する。

## 6. 10万字の長文での入力の軽さ

1. 10万字程度のテキストを貼り付けて（貼り付けの書式が無視され、改行がLFに正規化されることを確認する）、文字数が10万前後になることを確認する。
2. 続けて入力し、画面が固まらず応答することを確認する。

## 7. Windows・Linux両方での確認

それぞれのOSで:

1. 日本語入力ができることを確認する（LinuxはQt用IME連携が必要。README参照）。
2. 保存したファイルがUTF-8・LFであることを確認する。
3. セクション1〜6を実施する。

## 記録

- 実施したOS・バージョン、Qtのバージョン、結果（OK／NG／未確認）を記録する。
- 確認できていないOS・環境は「テスト済み」と書かず、「未確認」と明記する。
